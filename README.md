# gs-paginas

Piezas web publicadas de Growth\*Stars.

**Este repositorio es público por necesidad técnica** — GitHub Pages solo sirve
repos públicos en cuentas Free. Por eso acá va **únicamente** lo que está pensado
para verse desde afuera.

El contexto operativo, los contratos y todo lo financiero viven en `gs-boveda`,
que es privado y **nunca** se mezcla con esto.

## Qué no entra acá

- Montos, márgenes, saldos o punto de equilibrio
- Datos de contacto de clientes o colaboradores
- Contratos y contexto de proyectos
